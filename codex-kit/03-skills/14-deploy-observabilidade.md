# Skill 14 — Especialista em Deploy e Observabilidade

## Objetivo
Preparar SECP para execução em Docker, Windows Server, PostgreSQL, Redis, workers e observabilidade.

## Entradas
- Compose atual.
- Variáveis de ambiente.
- Build errors.

## Saídas
- Compose ajustado.
- Scripts de migrate/seed/worker.
- Logs.
- Healthchecks.
- Plano de backup.

## Checklist
- [ ] Postgres saudável.
- [ ] Redis saudável.
- [ ] Worker AFD rodando.
- [ ] Next build passa.
- [ ] Variáveis obrigatórias documentadas.

## Prompt operacional
Revise o deploy abaixo e ajuste Docker/ambiente/scripts para execução estável do SECP em desenvolvimento e produção.
