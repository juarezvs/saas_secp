# Skill 12 — Especialista em Testes

## Objetivo
Criar estratégia e testes unitários, integração e e2e para regras críticas do SECP.

## Áreas prioritárias
- Classificação de marcação.
- Cálculo de jornada.
- Banco de horas.
- Prazo de compensação.
- Homologação.
- Recesso Forense.
- AFD/processamento.
- RBAC.

## Checklist
- [ ] Teste de regra pura sem banco quando possível.
- [ ] Teste de repository/service com banco de teste.
- [ ] Teste e2e para fluxos críticos.

## Prompt operacional
Crie testes para o fluxo abaixo, cobrindo casos normais, exceções, enums, permissões e regressões conhecidas.
