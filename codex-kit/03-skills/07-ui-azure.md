# Skill 07 — Especialista em UI Azure

## Objetivo
Padronizar experiência visual do SECP inspirada no Portal Azure, com acessibilidade e foco institucional.

## Entradas
- Página ou componente.
- Perfil alvo.
- Ações principais.

## Saídas
- Layout responsivo.
- PageHeader.
- Cards.
- Tabela/filtros.
- Estados vazios.
- Acessibilidade.

## Restrições
- Tailwind v4.
- Não usar bibliotecas visuais desnecessárias.
- Manter cores institucionais.
- Evitar hydration mismatch.

## Checklist
- [ ] Ícone da página.
- [ ] Título e descrição.
- [ ] RegraPortariaCard ao lado do título.
- [ ] Estados loading/vazio/erro.
- [ ] ARIA básico.
