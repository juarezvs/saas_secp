# 01 — Prompt para Aplicar Padrão de Listagem

Aplique o padrão de listagem SECP nesta página/módulo: [INFORMAR MÓDULO].

Requisitos:

- filtros dentro da própria tabela;
- selects com aplicação imediata;
- inputs de texto com debounce de 1 segundos;
- consulta geral pesquisando os campos visíveis da tabela;
- itens por página dentro da tabela;
- paginação server-side;
- botões no topo direito: Exportar lista e Exportar PDF;
- exportação respeita filtros e ignora paginação;
- preservar permissões existentes;
- usar PageHeader com ícone e RegraPortariaCard popup;
- entregar versão final completa dos arquivos alterados.
